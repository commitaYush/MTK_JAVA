## About

This repository contains four beginner-level Java projects developed as part of the MTK Academy Project-Based Java Development Internship.

## Projects

### 1. Banking Management System

* Create account
* Deposit and withdraw money
* Check balance
* Display account details

### 2. Student Management System

* Add and view students
* Search students
* Update and delete records

### 3. Library Management System

* Add and view books
* Search books
* Issue and return books

### 4. Employee Management System

* Add and view employees
* Search, update, and delete records
* Calculate salary with a 10% bonus

## Technologies Used

* Java
* OOP (Classes, Objects, Constructors, Encapsulation)
* ArrayList
* Exception Handling

## Requirements

* Java Development Kit (JDK)
* VS Code, IntelliJ IDEA, or Eclipse

## How to Run

Compile and run each project separately.

Example:

```bash
javac BankingManagementSystem.java
java BankingManagementSystem
```

Use the corresponding Java filename for the other projects.

## Data Storage

Data is stored temporarily in memory and resets when the program closes.
